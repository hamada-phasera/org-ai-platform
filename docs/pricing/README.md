## 価格を載せる前に直すこと

1. **エージェント化提案の Opus 固定を外す** — 会話の3ターン目以降ほぼ毎回発火し、
   梅プランでは原価の93%を占める。一次判定を安いモデルに落とせば約1/10になる。
2. **Gemini 無料枠から離脱する** — 公式に「入力内容が Google の製品改善に使われる」と
   明記されている。領収書やLINEのやり取りを扱う以上、有償プランの土台にできない。
3. **表示モデル名を実態に合わせる** — 梅に「Claude Haiku 4.5」と表示しているが
   Gemini flash-lite が動く。3プラン中2つで、顧客が受け取っていないモデル名を出している。

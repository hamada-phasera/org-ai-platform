## 決めごと（v3）

- 白基調＋ブルーバイオレット `#635BFF`。青は「導く色」で塗り面積は小さく
- 面は不透明な白＋ソフトシャドウ3段（sh-sm / sh-md / sh-lg）。**backdrop-filter／半透明ガラスは使わない**（v2 リキッドガラスは全面取り下げ）
- 角丸 8 / 12 / 16。フォント Figtree + Noto Sans JP、数字は等幅
- ブランドのグラデーションは 3px ストリップのみ（ヒーロー・モーダル上端）。面には塗らない
- **ダークモード廃止**。テーマトグルは置かない
- **部署トグル（すべて/営業部/マーケ部/経理部/データ分析/総合）をトップバーに常設**
- TOP は最小構成のまま（一行入力＋入口4つ、KPI数字なし。例外は承認件数のみ）

## ファイル

- `*.dc.html` × 12 — デザインキャンバスのアートボード（デスクトップ7・基盤2・モバイル3）
- `canvas.json` — 配置・ページ（TOP / 画面 / 基盤とモバイル）・付箋
- `char-*.png` — 部署キャラクター（身元表示用）
- `build-stripe.mjs` — 全ボードの生成元。トークン・サイドバー・トップバーはここで一元管理
  （`node build-stripe.mjs` で `out/` に再生成）

## 実装への反映（未着手）

アプリ実装は `feat/ui-v2` ブランチ（現状はリキッド質感の v2）。
v3 化は `apps/web/src/index.css` のトークンと `ui/` プリミティブの差し替えが中心で、
画面構造・IA は v2 実装と同一のため作り直しは不要。
